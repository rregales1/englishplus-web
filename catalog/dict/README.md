# English+ word data

Definitions, pronunciations, translations, synonyms and antonyms in this folder are
derived from the English Wiktionary (https://en.wiktionary.org), written by the
Wiktionary contributors and licensed under the Creative Commons
Attribution-ShareAlike 4.0 License (https://creativecommons.org/licenses/by-sa/4.0/).
This data is shared under the same license.

Example sentences come from Tatoeba (https://tatoeba.org), licensed under
CC BY 2.0 FR (https://creativecommons.org/licenses/by/2.0/fr/). Each one keeps its
Tatoeba sentence number.

Pictures are not stored here: only the address of the main picture of each
Wikipedia article, which stays on Wikimedia Commons with its own license.

All of it was prepared for the English+ app, which reads these files instead of
querying Wikimedia and Tatoeba for every word.
